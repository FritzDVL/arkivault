## The True On-Chain Architecture

Every device handles its own data fetching directly via the Arkiv L2/L3 RPC network. No centralized middleman database exists.

```
[ Laptop / Vault ]  ◄──(RPC Read/Write)──►  [  ARKIV L3 DB-CHAIN  ]  ◄──(RPC Read/Write)──►  [ Mobile / Web client ]
 (Local Markdown)                          (Universal Data Layer)                            (Decentralized View)

```

1. **The Laptop (The Writer):** Runs a simple local background script (or directly inside an Obsidian plugin wrapper) that watches your Markdown files. When you save a note, it formats the file and pushes it directly onto Arkiv as an **Entity**.
2. **The Cloud Storage:** Arkiv's decentralized network receives the entity, indexes it by your wallet address, and mirrors it globally across its node operators.
3. **The Phone / Other Desktops (The Readers):** You open a lightweight web app or mobile view. It uses your cryptographic wallet to query Arkiv’s `buildQuery()` via standard RPC. It immediately pulls down all your notes from the chain, letting you read or edit them from anywhere.

## 🛠️ The Hackathon Implementation

Because time is short, the fastest way to build this for the hackathon is a **Next.js Web Application**. You can run it locally on your laptop, access it via your phone's browser, and it will interact *exclusively* with the Arkiv testnet (`braga`).

### 1. Initializing the Arkiv Client

First, initialize the type-safe client using the `@arkiv-network/sdk`. Notice how it talks straight to the network without using any standard database connection strings.

```typescript
// lib/arkiv.ts
import { createPublicClient, createWalletClient, http } from "@arkiv-network/sdk";
import { braga } from "@arkiv-network/sdk/chains";

// Used for reading your second brain across any device
export const publicClient = createPublicClient({
  chain: braga,
  transport: http(),
});

```

### 2. Pushing a Note On-Chain (Write)

When you finish writing a note on your computer, your app publishes it directly to the blockchain as a structured entity. We add attributes so it is easily queryable.

```typescript
// lib/syncNote.ts
import { publicClient } from "./arkiv";
import { eq } from "@arkiv-network/sdk/query";

export async function saveNoteToBlockchain(walletAddress: string, note: { id: string; title: string; content: string; tags: string[] }) {
  const query = publicClient.buildQuery();
  
  // Create the structured payload
  const entityPayload = {
    id: note.id,
    title: note.title,
    content: note.content,
    updatedAt: Date.now()
  };

  // We write it to Arkiv as an entity owned by your Web3 identity
  // Note: All data on Arkiv is public by default, so in a production app 
  // you would encrypt the payload before saving it!
  const tx = await publicClient.arkiv.createEntity({
    payload: Buffer.from(JSON.stringify(entityPayload)),
    attributes: {
      category: "second-brain",
      tags: note.tags.join(","),
      noteId: note.id
    },
    // Keep it available in the query index for 30 days
    expires_in: 2592000 
  });

  return tx;
}

```

### 3. Syncing Across Your Phone or Desktop (Read)

When you pick up your phone, the browser queries the Arkiv network directly using your wallet address to pull down your complete second brain setup.

```typescript
// lib/getBrainNotes.ts
import { publicClient } from "./arkiv";
import { eq } from "@arkiv-network/sdk/query";

export async function fetchSecondBrain(userWalletAddress: string) {
  const query = publicClient.buildQuery();
  
  // Query Arkiv directly for your notes index
  const result = await query
    .where(eq('category', 'second-brain'))
    .ownedBy(userWalletAddress)
    .withAttributes(true)
    .withPayload(true)
    .limit(50)
    .fetch();

  // Parse the raw blockchain buffer payloads back into readable notes
  return result.entities.map(({ payload, attributes }) => {
    const data = JSON.parse(payload.toString());
    return {
      id: data.id,
      title: data.title,
      content: data.content,
      tags: attributes.tags ? attributes.tags.split(",") : [],
      updatedAt: data.updatedAt
    };
  });
}

```
